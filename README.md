# 영어 모음 점검기

영어 모음을 원어민에 가깝게 내고 싶은 한국어 화자가 단어 12개(heed, hid, hayed, head, had, hod, hawed, hoed, hood, who'd, hud, heard)를 녹음하면, 바탕 논문과 같은 방법으로 원어민 기준(Hillenbrand 외, 1995)과의 거리를 잽니다. 그리고 원어민 범위 밖에 있는 모음을 짚어 주고 고칠 방향을 알려 줍니다.

- 바탕 논문: 이현우(2026), 「영어 최초 노출 연령과 성인기 영어 문법성 판단·모음 음향 특성: 가족 4명 사례 연구」
- 만든 사람: 이현우 (AI와 함께 바이브코딩)

## 실행 방법

설치가 필요 없습니다. 서버나 빌드 과정도 없습니다.

1. ZIP을 새 폴더에 풉니다.
2. `index.html`을 크롬, 사파리, 엣지 가운데 하나로 엽니다(더블클릭).
3. 마이크 녹음이 안 되면 다음 둘 중 하나를 쓰세요.
   - 파일 버튼으로 녹음 파일을 올립니다.
   - 폴더에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 엽니다.

   일부 브라우저는 `file://`로 연 페이지에서 마이크를 막기 때문입니다. 공개 URL(https)에서는 바로 됩니다.

인터넷이 끊겨 있으면 글꼴만 기본 글꼴로 바뀌고, 분석은 그대로 됩니다.

## 써 보는 순서(사용자가 할 일 세 가지)

1. **기준을 고르고 단어 12개를 녹음합니다.**
   - 기준: 성인 남성, 성인 여성, 아동 10~12세(남녀 합침) 가운데 하나를 고릅니다.
   - 녹음: 단어 카드마다 **녹음 → 멈추기**를 누릅니다. 4초가 지나면 자동으로 멈춥니다.
   - 마이크 없이 보려면 **원어민 음성으로 체험** 또는 **한국어 화자 경향 예시**를 누릅니다.
2. **결과를 확인합니다.** 결과 칸에 다음이 나옵니다.
   - 정적 거리와 원어민 90백분위 비교("원어민 범위 안/밖")
   - 모음별 거리 막대
   - 모음 지도(원어민 평균과 범위 원, 내 모음 점)
3. **가장 먼 모음을 다시 녹음합니다.** 연습 칸에서 자동으로 골라 준 모음의 교정 팁을 보고 **다시 녹음**합니다. 모음 거리와 전체 거리가 "얼마에서 얼마로" 바뀌었는지 나옵니다.

## 논문에서 가져온 것

- **방법**(논문 3.4절)
  - 포먼트: Burg, 0.01초, 5개, 창 0.025초, 선강조 50 Hz, 상한 남 5000 Hz·여 5500 Hz
  - 측정: 20·50·80% 지점
  - 정규화와 거리: Lobanov 정규화, 원어민 평균점과의 정적 거리, 20→80% 동적 거리
  - 판정: 같은 집단 원어민 거리의 90백분위 이하면 "원어민 범위 안"
- **모음 구간**: 논문 부록 C 조건 A(원어민도 유성음 자동 구간, 문턱 0.45)를 씁니다. 원어민 90백분위는 논문 표와 같습니다(남 0.370, 여 0.427).
- **결과**(4.2절, 5.2절): 한국어 화자에게 특히 먼 모음 세 가지를 교정 팁과 가상 예시에 씁니다.
  - head·had(/ɛ/, /æ/)
  - hod(/ɑ/)를 'ㅗ'처럼 내는 경향

## 데이터와 비밀값

- **개인정보 없음**: 앱에 들어간 데이터는 Hillenbrand 외(1995)의 공개 자료와, 그것으로 만든 요약값뿐입니다. 논문의 가족 녹음은 넣지 않았습니다.
- **녹음은 브라우저 안에서만**: 사용자 녹음은 브라우저 메모리에서만 분석되고, 어디로도 전송되거나 저장되지 않습니다. 페이지를 닫으면 사라집니다.
- **환경 변수 없음**: 외부 AI 서비스나 API 키를 쓰지 않습니다.
